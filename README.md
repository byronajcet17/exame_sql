# TIENDA

Sistema de Gestión de Inventario
Descripción del proyecto

TechZone es una tienda dedicada a la comercialización de productos tecnológicos como laptops, teléfonos inteligentes y accesorios.

El presente proyecto implementa una base de datos relacional utilizando PostgreSQL para mejorar la administración del inventario, clientes, proveedores y ventas.

El sistema permite:

Registrar categorías de productos.
Registrar productos y controlar su stock.
Registrar proveedores.
Registrar clientes.
Registrar ventas.
Asociar productos con cada venta.
Consultar productos con poco stock.
Obtener las ventas de un período determinado.
Identificar los clientes con mayor cantidad de compras.
Identificar los productos más vendidos.
Consultar ventas dentro de un rango de fechas.
Identificar clientes que no han realizado compras recientemente.
Registrar ventas mediante un procedimiento almacenado.
Validar automáticamente la existencia del cliente.
Validar automáticamente la disponibilidad del inventario.
